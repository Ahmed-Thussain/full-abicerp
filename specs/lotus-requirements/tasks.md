# Lotus Requirements: Tasks

Rules for whoever runs a task:
- Do only what the task says, in the file it names. Do not touch other files.
- Read the function named in the task before you edit it. Copy the style of the code around it.
- Migrations: name the file `NNN_version_NNN.php` where NNN is the highest number in that module's `migrations/` folder plus 1. Copy the class shape of `modules/accounting/migrations/147_version_147.php`. Use `field_exists` / `table_exists` checks so it can run twice.
- New settings use `add_option('name', 'default')` in the module's `install.php` AND in the migration.
- New user-visible text goes in the module's `language/english/<module>_lang.php` (and `arabic` if the same key list exists there).
- After each task, load the page or run the code path once and check for PHP errors.

Format: `- [ ] Txxx [P] [US] description`. `[P]` means it can run in parallel with its neighbours.
